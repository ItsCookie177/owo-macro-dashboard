# OwO Macro — Panduan Logo (ringkas)

## 1. Logo
- **Ide**: Huruf **O–w–O** yang langsung terbaca wajah — logo menyebut namanya sendiri dalam satu bentuk.
- **Versi**: horizontal (utama) · stacked · simbol saja · wordmark saja · favicon (potongan kecil).
- **File**: `kit/*.svg` (master vektor) · `kit/variants/*` (hitam/putih/coral) · `kit/web/*` (favicon + icon set).

## 2. Ruang bebas
Sisakan ruang kosong minimal **1 × tinggi cincin mata** di semua sisi logo. Ruang ini ikut mengecil saat logo diperkecil — jangan pakai jarak tetap.

## 3. Ukuran minimum
| Versi | Layar | Cetak |
|---|---|---|
| Horizontal | 120 px lebar | 30 mm |
| Simbol | 16 px (pakai file `favicon`) | 6 mm |

## 4. Warna
| Nama | HEX | RGB | CMYK | Pantone |
|---|---|---|---|---|
| Coral (utama) | `#E8622C` | 232 98 44 | 0 / 58 / 81 / 9 | ≈ 165 C — verifikasi fisik |
| Ink | `#2A2521` | 42 37 33 | 0 / 12 / 21 / 83 | ≈ Black 7 C |
| Cream | `#FAF7F2` | 250 247 242 | 0 / 1 / 2 / 2 | ≈ 11-0605 TCX |
| Putih | `#FFFFFF` | 255 255 255 | 0 / 0 / 0 / 0 | — |

**Kombinasi yang disetujui**: coral penuh di krem/putih · putih di coral · putih di ink · hitam di putih. Versi putih sudah dipotong lebih tipis (iradiasi optik). Di foto: pakai versi putih/hitam di area tenang, atau taruh di dalam tile coral.

## 5. Tipografi
- Judul: **Plus Jakarta Sans ExtraBold** · teks: Regular/Medium · data: **JetBrains Mono**
- Lisensi: SIL Open Font License (boleh dipakai untuk logo). Glyph wordmark sudah di-outline jadi path — jangan ketik ulang.
- Fallback web: `system-ui, sans-serif`.

## 6. Jangan
Jangan diregangkan · jangan diwarna di luar palet · jangan diputar · jangan ditambah bayangan/outline/gradasi · jangan diubah jarak bagian lockup · jangan di atas foto ramai tanpa container · jangan mengetik ulang wordmark memakai font.

## 7. Kontak
